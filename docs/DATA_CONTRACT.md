# KuaiLive-M3 数据契约

## 最小跨域推荐文件

以下文件构成项目的最小可用数据集：

| 文件 | 作用 |
|---|---|
| `user_id_set.csv` | 两域共享的匿名用户集合 |
| `author_profile.csv` | 直播作者/内容创作者画像 |
| `photo_interaction.csv` | 短视频源域行为 |
| `live_interaction.csv` | 直播目标域观看和交互 |

校验器只检查文件是否存在、类型是否正确，不在校验阶段加载大型文件；云端一键脚本还会检查大文件体积和断点续传标记，避免误读未下载完成的 CSV。

## 内容与行为扩展文件

| 文件 | 作用 |
|---|---|
| `photo_play.parquet` | 短视频逐次播放事件 |
| `photo_meta.parquet` | 短视频元数据 |
| `photo_tag.csv` | 短视频标签和类目 |
| `photo_emb_128.parquet` | 短视频内容 Embedding |
| `live_show.parquet` | 直播曝光日志 |
| `live_room_meta.parquet` | 房间生命周期和元数据 |
| `live_emb_64.parquet` | 房间级直播表示 |
| `live_emb_128_ts/` | 带时间戳的直播片段表示分片 |
| `live_comment.csv` | 评论行为 |
| `live_like.csv` | 点赞行为 |
| `live_share.csv` | 分享行为 |
| `live_questionnaire.csv` | 显式满意/不满意反馈 |

## 三层“内容信息”边界

1. `photo_tag`、房间元数据：离散标签和静态属性。
2. `photo_emb_128`、`live_emb_64`：视频/房间级预计算表示。
3. `live_emb_128_ts`：随直播内容变化的片段级预计算表示。

公开数据没有原始直播视频、音频和逐字字幕。因此项目可以研究动态内容融合、对齐和量化，但不能声称训练了原始直播 MLLM 内容编码器。

## 数据切分

- 源域短视频只用于训练用户跨域兴趣表示。
- 目标域直播行为按用户时间顺序做 80/10/10 切分。
- 1% 冒烟实验先在目标域去重后执行用户 5-core、作者 2-core；源域只保留这些用户及目标域候选作者。正式对齐官方协议时再单独报告双域迭代 5-core 结果。
- 测试时间之后发生的行为、问卷和内容状态不能进入训练特征。
- 动态片段只能使用推荐决策时间之前已经生成的 Embedding，避免未来信息泄漏。

## 本地目录

Hugging Face 当前以扁平根目录发布多数文件，`live_emb_128_ts` 为分片目录。本项目按这一公开布局校验。原始数据应放在仓库外，或放入已被 Git 忽略的 `data/`。
